# Glossaire

| Acronym | Role Title | Description |
|---|---|---|
| ARF | Functional Architect | Responsible for maintaining the relationship with the end user (Business Team/Customer). They elicit requirements and represent them to development teams, designing the logical functions and activities the application must perform. |
| ART | Technical Architect | Ensures technical solutions align with business goals and provides direction to project teams. They define the physical elements, infrastructure, and information links of the application. |
| ASI | Information System Analyst | Responsible for identifying user requirements, creating data models, and analyzing application specifications. |
| ASL | Logical Security Administrator | Controls and grants user access rights based on the hierarchy of the security domain, typically using the REUNIS tool. |
| ASM | Applications Service Manager | Has overall responsibility for RUN Services Delivery (including small enhancements) and ensures teams meet SLA and budget obligations. |
| B-PM | Business Project Manager | Manages and oversees the IT project from introduction to termination. They agree on specifications, UAT, costs, and resources in collaboration with the IT project manager. |
| CPRA | DRP Correspondent | In charge of Disaster Recovery Plan (DRP) management and the coordination of DRP tests. |
| DBA | Database Administrator | Uses specialized software to store and organize data. Responsibilities include capacity planning, installation, configuration, security, troubleshooting, and data recovery. |
| DEV | Developer | Responsible for developing the actual code of an application. |
| Expert métier | Business Team (SME) | Business subject matter experts or key users participating in an ICT project. |
| ITE-TN | BUILD Technical Integrator | Participates in technical architecture definition, integrates and deploys new code into production, and transfers knowledge to RUN teams. |
| ITE-VCO | RUN Technical Integrator | Ensures daily operational quality and compliance with service level commitments, including security standards, monitoring, and configuration management. |
| IT-PM | IT Project Manager | The person responsible for leading a project from inception to execution, managing people, resources, and project scope. |
| MOA | Business Team | The ex-PSA term for the Business Team or SMEs participating in an ICT project. |
| MOE | IT Team | The ex-PSA term for the ICT experts participating in an ICT project. |
| OPE | IT Operations Entity | Staff in charge of monitoring consoles and receiving alarms. They provide Level 1 technical support and dispatch incidents to other teams as needed. |
| PFA | Functional IT Application Support | Owner of an application across its entire lifecycle, managing change management, enhancements, monitoring, and deployment. |
| PGA | Global IT Application Leader | Guarantees the continuity of operation for applications in production and serves as the primary contact for the Business Team. |
| PMO | Project Management Office | Sets and ensures standards for project management across the organization, acting as the keepers of best practices and status reporting. |
| POA | Operational Application Lead | Ensures access rights, training, and assistance to users within a specific geographical scope. They analyze change requests to ensure coherence with business needs. |
| PTA | Technical Application Leader | An outsourced role within the RUN organization that provides technical expertise for one or several applications. |
| RSECU | Security Referent | Refers to the global security central team. |
| RTECH | Technical Referent | Infrastructure stakeholders, including Network experts, Telecom experts, and DBAs. |
| RTST | Qualification Tester | Responsible for IT testing and the qualification testing phase. |
| RT-PERF | Performance Tests Manager | Responsible for managing and executing load and performance tests. |
| TFA | Techno Functional Analyst | Creates the Technical Design Dossier, manages configuration, and analyzes technical incidents or correction requests during the RUN phase. |
| TPM | Technical Project Manager | Manages a supplier's contribution regarding quality, timelines, and budget, while coordinating design and development activities. |
| T-SFAC | Components Integration Tester | Usually a supplier role in charge of testing the integration of components following initial development and unit tests. |
| UFI | End User / Key User | Representative of a business process with a leading role in the implementation of a project. |
