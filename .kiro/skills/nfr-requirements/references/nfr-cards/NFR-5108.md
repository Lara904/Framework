# NFR-5108 — Any new application or any new applicative occurrence or major evolution must use IndusGen tools

## 1. NFR Metadata

- **ID:** NFR-5108
- **Title:** Any new application or any new applicative occurrence or major evolution must use IndusGen tools
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** For any new application and major evolution, it is mandatory to use IndusGen base and tools. Realization: You must use IndusGen tools and IndusGen/Web for the delivery and IndusGen Base for the exploitation.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- For any new application and major evolution, it is mandatory to use IndusGen base and tools.

Realization:
- You must use IndusGen tools and IndusGen/Web for the delivery and IndusGen Base for the exploitation. 
For each tool, it is mandatory to install the last version and use the IndusGen product modules. 
The supervision module srv00 of IndusGen Base is installed and activated.
All functions are implemented and tested in preproduction and production.
- Cloud context: N/A

Useful links or documents:
- All documents you need for using IndusGen tools are referred in ITE web site section Common Tools at Support section
