# NFR-6111 — Differences between access rights defined in the security reference and the actual rights on the systems in operation must be checked

## 1. NFR Metadata

- **ID:** NFR-6111
- **Title:** Differences between access rights defined in the security reference and the actual rights on the systems in operation must be checked
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** This provision aims to ensure that there is no gap between the rights defined in the security referential (REUNIS) and the actual rights in place on targeted systems. It detects the administration actions performed outside the REUNIS tools or the anomalies during synchronisations with the security referential.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- This provision aims to ensure that there is no gap between the rights defined in the security referential (REUNIS) and the actual rights in place on targeted systems. It detects the administration actions performed outside the REUNIS tools or the anomalies during synchronisations with the security referential.
Its implementation can take the form of regular audits, or by the technical methods proposed by REUNIS.
