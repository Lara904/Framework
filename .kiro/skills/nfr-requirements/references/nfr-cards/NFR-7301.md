# NFR-7301 — The system must easily enable the users to indicate its reference name as it is written in applications repository to Help Desk

## 1. NFR Metadata

- **ID:** NFR-7301
- **Title:** The system must easily enable the users to indicate its reference name as it is written in applications repository to Help Desk
- **Primary Category:** Maintainability

---

## 2. Executive Summary

- **The "Goal":** The help desk mainly faces the following problem: user calls not knowing the REFLEX name of the application for which they are calling. It built its intervention ranges by considering that the application respects following points: REFLEX name specifies for each application in development, pre-production and production to know the related server.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Maintainability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- REFLEX update:
- Purchased software package does not comply with coding standards:
If the symbol appears on screen, put it in the description of the application in REFLEX. 

SAP Applications:
- The name of the applications in SAP-LOGON starts by REFLEX name.
In case of shared server, put in the domain name as machine name REFLEX.
Names of all the servers of the application (applications and database) must appear in REFLEX (including the ITS server if there is one) (« machine » zone).
In case of possible access to the application through a browser, put the input URL in the application in « point d ’entrée » [input point] zone of REFLEX. 

LSI BO Applications:
- Put the REFLEX name in start of the universe description.

WEB Applications:
Put the input URL in the application in « point d ‘entrée » [input point] zone in REFLEX.

No WEB client-server applications, no DOMINO:
- Put the REFLEX name in all the screens and in header of the error messages. 

DOMINO Applications:
- Compliance with the nomenclature rules of the physical files: PRDxx/BASE/PRDNxxx.NSF (x being free).

Case of « groupware » applications:
- Name of physical file: PRDnn/BASE/PRDDN000.NSF. The DOMINO instance is to be entered in REFLEX as a machine name (SYSID).
Put the input URL in the application in « point d ‘entrée » [input point] zone of REFLEX.

NOMAD Applications:
- The REFLEX name must be:  LSI/ short name of the application.

SQL/SERVER Applications:
- The developers must put the REFLEX name of the application on the first page of the application and repeat it on each screen.
