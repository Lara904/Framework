# NFR-5404 — System infrastructure class and DRP (PRA) test

## 1. NFR Metadata

- **ID:** NFR-5404
- **Title:** System infrastructure class and DRP (PRA) test
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** The project has to determine the DRP requirements for the future application, regarding: The RTO (Recovery Time Objective): how long the service can be hanged in case of a major disaster? The RPO (Recovery Point Objective): how much data can be lost, between the last backup and the crash?
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- The project has to determine the DRP requirements for the future application, regarding:
- The RTO (Recovery Time Objective): how long the service can be hanged in case of a major disaster?
- The RPO (Recovery Point Objective): how much data can be lost, between the last backup and the crash?
- See more in the DRP Glossary for the complete meaning of RPO/RTO and the scale used to qualify these requirements.

Once the RTO/RPO are defined, the project has to deploy an architecture, which meets all the requirements of both classes. The RPO is used to choose a backup strategy, when the RTO determines a redundancy level and a recovery procedure.
See also the architecture models for the different classes.

By the end of the project, and before the application goes into production, the recovery plan has to be tested, according to the PRA testing strategy.
- Cloud context: during the CCT, depending on the criticality of the applications, it is established with the project manager how long an application can remain out of use, if data can be lost between the last backup and the system or application crash

Realization:
- Cloud context: During the pre-production phases, a list of tests is established by cutting a node, cutting the database and various scenarios to judge the state of the application. It will be possible to establish how many time will be needed to rehabilitate the activities as quickly as possible. At the moment there is no identified PRA, it will be necessary to wait until 2019
