# NFR-3202 — The usage of the system through the PSALib' environment must be operational (technical and organization aspects)

## 1. NFR Metadata

- **ID:** NFR-3202
- **Title:** The usage of the system through the PSALib' environment must be operational (technical and organization aspects)
- **Primary Category:** Compatibility

---

## 2. Executive Summary

- **The "Goal":** PSALib’ is a new device that permits to access securely PSA applications and datas outside PSA locals. All the flows and protocols from client to servers must be described and opened in the firewall.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Compatibility standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- From the outside, you must check that you have access to the applications
- For more information use the PSALib’s Portal:  http://psalib-portal.inetpsa.com/

### Reference Links

- http://psalib-portal.inetpsa.com/
