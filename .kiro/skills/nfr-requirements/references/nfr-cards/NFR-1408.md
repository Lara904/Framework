# NFR-1408 — SOX treatments must be identified and described (functionally & technically)

## 1. NFR Metadata

- **ID:** NFR-1408
- **Title:** SOX treatments must be identified and described (functionally & technically)
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** Functional specifications document: The functional identification and description of SOX treatments must be done in the Functional Specifications documents, in the Introduction chapter to describe globally the SOX elements for the application, and in other chapters to detail all SOX relevant information regarding data, functions and interfaces. DLTI should be properly documented including the details requested into SOX sections.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).
