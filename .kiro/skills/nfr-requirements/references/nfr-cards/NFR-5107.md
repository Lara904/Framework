# NFR-5107 — Anticipation planning for the CAB (DDCE changes coordination) must be up to date

## 1. NFR Metadata

- **ID:** NFR-5107
- **Title:** Anticipation planning for the CAB (DDCE changes coordination) must be up to date
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** In order to avoid conflict between main changes, important for the BUSINESS or for the infrastructure, as soon as the project manager knows when he should put in production his project, he must book the dates in the ANTICIPATION sheet of the CTR (Change Real Time) application. First to validate the GOPROD date, he must check if the event already booked in the CTR anticipation, are compatible or not this his project.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- In order to avoid conflict between main changes, important for the BUSINESS or for the infrastructure, as soon as the project manager knows when he should put in production his project, he must book the dates in the ANTICIPATION sheet of the CTR (Change Real Time) application.
First to validate the GOPROD date, he must check if the event already booked in the CTR anticipation, are compatible or not this his project.
If the GOPROD date change, the project manager has to change the date.

Realization:
- All functional event are in YELLOW.
All event linked to the bank are in grey.
All network even are in Violet.
All infrastructure event, except network, are in blue.
Your RDSM can help you.
