# NFR-2301 — The system's initial capacity is able to deal with the starting needs and also their anticipated increase

## 1. NFR Metadata

- **ID:** NFR-2301
- **Title:** The system's initial capacity is able to deal with the starting needs and also their anticipated increase
- **Primary Category:** Performance Efficiency

---

## 2. Executive Summary

- **The "Goal":** The applications should be robust to an exceptional increase in the input flow volume. This criterion generally involves batch processing.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Performance Efficiency standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- The application should implement a processing logic associated to the application threshold (linked to business activity indicators).
- The Inputs / Outputs should be configurable:
- Batch processing:
- Limitation to the data volume source to be considered;
- Limitation of processing by non-processed data recycling;
- Regulation configured by a privileged user (via steering base) for processed data volumes.
- Message processing:
- Parallel processing of multiple processes.
