# NFR-7004 — The Cloud-Native principle must be implemented

## 1. NFR Metadata

- **ID:** NFR-7004
- **Title:** The Cloud-Native principle must be implemented
- **Primary Category:** Maintainability

---

## 2. Executive Summary

- **The "Goal":** The cloud-native principles is a methodology or set of principles for building scalable and performant, independent, and most resilient enterprise applications. These cloud-native principles are composed of 12 factors plus other factors that add to complement.
- **Why it matters:** If not implemented, all applications/projects to be deployed in a cloud (private or public).. Failure to comply may lead to non-conformance with group standards and audit failures.

---

## 3. Technical Requirements

### Key Constraints

- All 12 factors must be implemented and when it is relevant and especially in line with the SLA and the FinOps you can implement additional criteria.
- All criteria will be implemented and validated prior to the TCC (CTC) because they could impact the cost proposal
- It is mandatory to describe project infrastructure “As Code” and “Automate” the deployment from code repository to cloud environment.
- When a proposed Stellantis cloud-native pattern is corresponding to the project needs, use it as a starting point.

### Reference Links

- https://development.psa-cloud.com/#/cloud/cloud-native/overview
- https://12factor.net/

---

## 4. Applicability Checklist

Answer **Yes** to any of the following to confirm this NFR applies to your project:

- [ ] **Will the application be deployed or operated in a cloud environment (AWS, Azure, GCP)?**
- [ ] **Is the infrastructure managed as code (IaC) with automated CI/CD pipelines?**
- [ ] **Is the application expected to evolve continuously over a multi-year lifecycle?**
