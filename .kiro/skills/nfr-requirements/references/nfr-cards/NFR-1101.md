# NFR-1101 — The scheduling entities results are produced on time

## 1. NFR Metadata

- **ID:** NFR-1101
- **Title:** The scheduling entities results are produced on time
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** All scheduling entities (batchs) must be described in the detailed functional specifications. For each batch treatment, indicate the time when the result must be ready.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- The batches are described in the functional specifications, in the “Goals” chapter. So in the description of each batch, indicate:
- The periodicity of the batch (one a year, first Monday of each month, each day, every thirty minutes …),
- The exact time you want the result, for example 8AM each day.
- If UML and Enterprise Architect are used, the batches are described with use cases. In this case, put this information inside the description of batches use cases.
