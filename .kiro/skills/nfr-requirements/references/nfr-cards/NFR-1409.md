# NFR-1409 — The configuration of the OS must respect the SOX compliance rules

## 1. NFR Metadata

- **ID:** NFR-1409
- **Title:** The configuration of the OS must respect the SOX compliance rules
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** Each server of a sensitive (with I or C >= 3 in DICT) or audited (SOX or CAC) application must be patched at least once a year.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- All UNIX servers must be configured in CHKSEC to level 3.
- All UNIX servers of audited (SOX or CAC) applications must be configured as sensitive and with incidents activated.
