# NFR-3102 — Except derogation, the system uses the up to date certified technical stack

## 1. NFR Metadata

- **ID:** NFR-3102
- **Title:** Except derogation, the system uses the up to date certified technical stack
- **Primary Category:** Compatibility

---

## 2. Executive Summary

- **The "Goal":** All news applications or all major evolutions of applications must integrate the Product stack according to homologated versions of infrastructure products, referenced within CMS REFLEX. EOS products are not allowed: Operating system, Database and Middleware software into the impacted applications for the project should be under good support by vendor.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Compatibility standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- On Cloud platforms (AWS, AZURE, GCP …)
- Automatic updates must be implemented when it is possible and depending the SLA (Service Level Agreement) of the application.
- For managed services, the major updates are done automatically.
