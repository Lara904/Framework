# NFR-1402 — The details of personal data used are defined, including data minimization and retention period

## 1. NFR Metadata

- **ID:** NFR-1402
- **Title:** The details of personal data used are defined, including data minimization and retention period
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** Data Minimization:
In order to ensure the minimization of data, you have to determine whether the data should or should not be collected concerning the defined purpose: there must be a legitimate purpose for collecting these data (‘data must be relevant’) the data must be suitable to achieve the purpose (‘data must be adequate’)
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Data Minimization:
In order to ensure the minimization of data, you have to determine whether the data should or should not be collected concerning the defined purpose:
- there must be a legitimate purpose for collecting these data (‘data must be relevant’)
- the data must be suitable to achieve the purpose (‘data must be adequate’)
- the data must be necessary to achieve the purpose (‘data must be limited’)
- Personal data should only be stored as long as it is necessary to achieving the purposes of processing. A maximal retention period must be fixed, after which data must be destroyed or anonymized in a secure, irreversible way. It is recommended to set up notifications at the end of the retention period for each data category, or to set up automatic deletion of data when they reach the period’s end.
