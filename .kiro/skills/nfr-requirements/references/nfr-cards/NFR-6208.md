# NFR-6208 — The user's session must be controlled and protected

## 1. NFR Metadata

- **ID:** NFR-6208
- **Title:** The user's session must be controlled and protected
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** Control and protect the user's session (compliance, validity period, refresh, protection against theft, revocation...).
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Control and protect the user's session (compliance, validity period, refresh, protection against theft, revocation...).
