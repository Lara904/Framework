# NFR-6109 — Protection of data must be strengthened (dedicated storage or encryption)

## 1. NFR Metadata

- **ID:** NFR-6109
- **Title:** Protection of data must be strengthened (dedicated storage or encryption)
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** This provision aims to prevent the risk of unauthorised reading of this data. It can be implemented by establishing that the access to data is not possible apart from through the application process (encryption, etc.).
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- This provision aims to prevent the risk of unauthorised reading of this data.
It can be implemented by establishing that the access to data is not possible apart from through the application process (encryption, etc.).
- Cloud context: data must be set apart on a dedicated filesystem outside the container. In addition, this data must be encrypted if it is sensitive data, no one has the right to access it and see their content

Realization:
- Cloud context: database data must be encrypted and a password protection system must be in place to identify and filter users, not everyone has the right to access
- On AWS: Encryption must be activated wherever it is possible: S3, HDD, Database, and so on. An AWS Config must ensure all these objects are encrypted.
