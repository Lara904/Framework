# NFR-1411 — SOX Schedulers should be properly configured

## 1. NFR Metadata

- **ID:** NFR-1411
- **Title:** SOX Schedulers should be properly configured
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** For UNIX/LINUX or WINDOWS applications, $U (6.10.21 is the minimum version) is the adequate tool to be able to track properly any job change or failure into the logs. To be able to provide required information to auditors, 2 technical batches must be implemented.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- It should be verified that any critical or SOX batch into DLTI is configured into $U:
- - having automatic incident generation.
- - any modification is made on behalf of an approved change.
