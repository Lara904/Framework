# NFR-5104 — Any job submitted by a user shall be under exclusive control of application

## 1. NFR Metadata

- **ID:** NFR-5104
- **Title:** Any job submitted by a user shall be under exclusive control of application
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** No access to system commands by the user. Allow the user, and only him, to control the functional operating parameters of an application.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- No access to system commands by the user. 
Allow the user, and only him, to control the functional operating parameters of an application.
- Cloud context: to be able to execute application processes, you need to have a technical account that will be at the beginning of the project, you will not start any process with the root user

Realization:
- The job submission by user is done only through application menus or screens managing a parameter customized to his needs. 
The process triggered in this way should not seek interventions of operation and system integration to work.
- Cloud context: create a technical account for the application using the TAM tool, set rights for this account 
On AWS: Any specific account created on this platform must be registered in TAM. SSH Keys too.

Examples:
- Specific processing executed based on operation of a steering base. 
z/OS: BMP is triggered from transactions.
