# NFR-6112 — The test environments (including preproduction) use anonymized or pseudonymised data

## 1. NFR Metadata

- **ID:** NFR-6112
- **Title:** The test environments (including preproduction) use anonymized or pseudonymised data
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** Production data cannot be used as game testing in the development environment. It is requested to implement the suitable ways to anonymize and edit any that may be sensitive.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Production data cannot be used as game testing in the development environment. It is requested to implement the suitable ways to anonymize and edit any that may be sensitive. These means may be simple tools developed by integrators or studies. A simple transcoding table under the responsibility of PFA may suffice. When production data are mandatory, e.g. unrepeatable incident, a procedure for the control, monitoring and channelling actions on the data should be applied. There are in the market for specialized software packages facilitating anonymization of the data, but we have not approved, load the project, according to the importance and difficulty of implementation of anonymization, to serve the need.

Anonymize data (reversible or irreversible modes) reduces the need to control access to the data concerned; the choice of the measure results from the analysis of multiple access requirements to these data and risk if disclosed.
Key recommendation:
- Do not collect data at the level strictly necessary finesse.
- Divide the data, the risk of cross lift the anonymity.
- Enclose collecting and entering data by dividing.
- Do not provide systematically general query software.
- Prohibit some crosses.
- Guarantee irreversible anonymization by hash functions.
- Managing the confidentiality of the secret key.
