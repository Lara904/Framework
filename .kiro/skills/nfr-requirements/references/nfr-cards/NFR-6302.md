# NFR-6302 — The integration with the Corporate SOC is set

## 1. NFR Metadata

- **ID:** NFR-6302
- **Title:** The integration with the Corporate SOC is set
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** Integration with the Corporate SOC and / or a business for a good consideration of security incidents and Forensics For Cloud application: For this type of application when activity analysis is done in the cloud, the incidents are reported to the corporate SOC. Activity logs are backed up to be available for forensic investigation.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Integration with the Corporate SOC and / or a business for a good consideration of security incidents and Forensics
- For Cloud application:
- For this type of application when activity analysis is done in the cloud, the incidents are reported to the corporate SOC. Activity logs are backed up to be available for forensic investigation.
- The technical and functional log transfer, alert and incident management procedures are defined.
