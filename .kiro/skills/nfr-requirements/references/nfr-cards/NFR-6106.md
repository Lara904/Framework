# NFR-6106 — The system's security must be enhanced by a strict segmentation of server host network or server itself, or by a hardened operating system

## 1. NFR Metadata

- **ID:** NFR-6106
- **Title:** The system's security must be enhanced by a strict segmentation of server host network or server itself, or by a hardened operating system
- **Primary Category:** Security

## 3. Technical Requirements

### Key Constraints

- The major Plateforme AWS, AZURE & GCP are up to date regarding security patches to protect well all customer applications. During the test phases, it is necessary to simulate concrete cases. Run multiple queries to check the state of the platform as well as the network. Connect multiple users to maximize the architecture and see how it behaves.
- On AWS, AZURE and GCP: All recommendations must be followed to ensure a correct security of your accounts and your application. Before the go live and during all each application lifecycle.
