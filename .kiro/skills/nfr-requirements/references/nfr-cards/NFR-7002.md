# NFR-7002 — The Stellantis (Ex-PSA) continuous integration and qualimetric platforms (CIQ) should be used for all supported development languages

## 1. NFR Metadata

- **ID:** NFR-7002
- **Title:** The Stellantis (Ex-PSA) continuous integration and qualimetric platforms (CIQ) should be used for all supported development languages
- **Primary Category:** Maintainability

---

## 2. Executive Summary

- **The "Goal":** The development strategy is based on a global process represented by the Software Factory. CIQ is the Stellantis branding for « Continuous integration and quality platform »).
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Maintainability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- The development strategy is based on a global process represented by the Software Factory. CIQ is the Stellantis branding for « Continuous integration and quality platform »).
This software factory aims to give you the control on:
- Source code management
- Build process automation
- Development guidance using quality and technical indicators
- Application package delivery in a binary repository to be reused in the deployment phase (preprod / prod)
- Cloud Context: For CI pipeline, it is recommended to use CIQ (Team City) if possible. Otherwise when it is relevant, use the AWS, AZURE or GCP tools and this solution must be validated in TCC (CCT).
- Whatever context, for code application you must use Stellantis GitHub and Stellantis Artifactory.
