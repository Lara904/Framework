# NFR-6206 — The means to detect version's evolutions of the system must be implemented

## 1. NFR Metadata

- **ID:** NFR-6206
- **Title:** The means to detect version's evolutions of the system must be implemented
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** This provision aims, in particular during the delivery of software or after action by external support, to allow an inventory of modules that have been changed effectively. It is part of the system used to control the production environment, and attributed responsibility to the various different actors.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---
