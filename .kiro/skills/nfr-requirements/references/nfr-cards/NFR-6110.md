## 3. Technical Requirements

### Key Constraints

- This provision aims to reduce the risk of access to data from physical equipment (servers, arrays).
Its implementation means that this equipment is installed in premises that have access that is subject to a special procedure (i.e. access to the ZSR).
- Cloud Context: Customer Application is installed in the availability zone which refers to an isolated data center within a single region. Each availability zone includes multiple data centers, and no single data center is shared between multiple availability zones.
- Each cloud provider has its measures to secure access to these data centers.
- See Documentation below.
