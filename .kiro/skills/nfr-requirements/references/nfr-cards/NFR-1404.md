# NFR-1404 — The information on the system are up to date in the record of processing register ("data protection authority" declaration)

## 1. NFR Metadata

- **ID:** NFR-1404
- **Title:** The information on the system are up to date in the record of processing register ("data protection authority" declaration)
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** Check with your DPO/RCIR if the project/processing can be associated to one or more existing processing in the Group’s register “records of processing”. If matching, you should implement the requirements described in the register (the most demanding in the case of matching with multiple generic processing), If almost matching, you should ask the processing owner of the generic processing for adjusting it in order not to create a new generic possible, then see previous point,
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Check with your DPO/RCIR if the project/processing can be associated to one or more existing processing in the Group’s register “records of processing”.
- If matching, you should implement the requirements described in the register (the most demanding in the case of matching with multiple generic processing),
- If almost matching, you should ask the processing owner of the generic processing for adjusting it in order not to create a new generic possible, then see previous point,
- If no matching possible, you have to create a new generic processing in the register; contact the concerned business GDPR representative (RCIR for PCD) to do this.
