# NFR-7001 — The source code is under control (the SCM tool should be under PSA ownership)

## 1. NFR Metadata

- **ID:** NFR-7001
- **Title:** The source code is under control (the SCM tool should be under PSA ownership)
- **Primary Category:** Maintainability

---

## 2. Executive Summary

- **The "Goal":** This provision aims to limit the possible problems associated to malicious development. Through increased traceability and easier audits of codes, this provision contributes to dissuasion.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Maintainability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- This provision aims to limit the possible problems associated to malicious development. Through increased traceability and easier audits of codes, this provision contributes to dissuasion. Furthermore, a guarantee of the compilation environment allows a reduction in the possibility of introducing "malware" into the application.
Its implementation can, in particular, be based on the JIP integration platform for JAVA technology.
