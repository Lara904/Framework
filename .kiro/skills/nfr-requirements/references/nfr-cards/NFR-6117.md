# NFR-6117 — The data hosting in external storage is compliant with the confidentiality of the data

## 1. NFR Metadata

- **ID:** NFR-6117
- **Title:** The data hosting in external storage is compliant with the confidentiality of the data
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** Data hosting in external storage (e.g. cloud) : C1 or C2 data: Possible with no restriction C3 data: Possible with no encryption in “approved” cloud Microsoft otherwise with encryption
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Data hosting in external storage (e.g. cloud) :
- C1 or C2 data: Possible with no restriction
- C3 data: Possible with no encryption in “approved” cloud Microsoft otherwise with encryption
- C4: Must not be outside
