# NFR-6009 — Access to application must be closed when outside of users' working hours

## 1. NFR Metadata

- **ID:** NFR-6009
- **Title:** Access to application must be closed when outside of users' working hours
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** This provision aims to limit access periods just to those required, in order to reduce the potential for attack. This can be implemented by halting the application, by immediate rejection upon entry to the application, by a blocking filter established within a FW, etc.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- This provision aims to limit access periods just to those required, in order to reduce the potential for attack.
