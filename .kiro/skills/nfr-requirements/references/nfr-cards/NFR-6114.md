# NFR-6114 — Data must be erased during the restitution process of the supports

## 1. NFR Metadata

- **ID:** NFR-6114
- **Title:** Data must be erased during the restitution process of the supports
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** Erasing data carriers at the end of "life PSA" On Cloud platforms (AWS, AZURE, GCP …): Data and supports are stored on the cloud provider’s datacenters.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Erasing data carriers at the end of "life PSA"
- On Cloud platforms (AWS, AZURE, GCP …):
- Data and supports are stored on the cloud provider’s datacenters.
- Partner or actor of the data restitution must verify the erasing of own application data.
- Otherwise, the cloud providers offer sufficient guarantees for customers data and them global security (specialy for erasing data and supports when data deleted on the cloud). See usefull links below.
