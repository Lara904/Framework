## 3. Technical Requirements

### Key Constraints

- This requirement refers to the state of being in accordance with established safety standards of the technical environments. Indeed, these must be compatible between the security level of our information system measure by control tools (e.g. anomalies CHKSEC, CERBERE) and the evaluation rules of the AICT.
- A security portal, to measure the DICT level reached by the servers and the applications and to compare it with the DICT requested by the MOA and filled in REFLEX, can monitor the security level of our information system (E.g. SAFE)
