# NFR-6108 — The system is deployed on an environment dedicated for itself or for a group of systems

## 1. NFR Metadata

- **ID:** NFR-6108
- **Title:** The system is deployed on an environment dedicated for itself or for a group of systems
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** This provision aims to reduce the risk of compromising an application from another application whilst they share the same environment. Its implementation means the use of dedicated operating systems for each application, unless the applications have the same users.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Cloud context: Each application including a need for high performance (critical application) must be implementing on its own in a dedicated environment: That is done by design because of our choice to separate projects by subscriptions (One project = one subscription) on all the cloud provider platforms. With the project manager and the technical architect for its implementation. See the system requirements for optimal performance.
