# NFR-5105 — System's operational information is complete and up to date in operational repositories (CMDB)

## 1. NFR Metadata

- **ID:** NFR-5105
- **Title:** System's operational information is complete and up to date in operational repositories (CMDB)
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** Automates must be defined in REFLEX with the network name and equipment location (building, step, pillar). Consistency must be checked with the name of the equipment in SAIG parameters.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Automates must be defined in REFLEX with the network name and equipment location (building, step, pillar). Consistency must be checked with the name of the equipment in SAIG parameters. This verification is to be done before Orientation committee of preparation in start-up.
Define the PRA criteria of the application (Tolerance to the shutdown duration, Tolerance for data loss, inter BU classification, intra BU classification, consistency group, functional BU). To deduce the necessary PRA documentation and update it.
- « Open » Case: the Operative ranges (GAOP) and the Alarm files (FICA: actions to be performed according to an alarm message) are in the Focus server
- z/OS Case: TWS instructions (operator’s instructions) are filled in TWS.
- On Cloud platforms (AWS, AZURE, GCP …)
- The application documentation must be written and up-to-date. All interlocutors must be referenced in Reflex and the name of subscription’s space.
- Security: Orientation Committee conclusion, NFR document, Matrix Access, have to have their lync in the application’s CMDB base. 

Realization:
- Operative range (GAOP document type):
- Is drafted according to its objective by « experts système » [system experts], by product or application system integrators, by CAO support for CAO applications;
- Is intended for Operations who must approve it (through “REDEX” application);
- Can be valid for several applications;
