# NFR-1401 — A high-level description and risk analysis on personal data has been conducted on the prestudy scope

## 1. NFR Metadata

- **ID:** NFR-1401
- **Title:** A high-level description and risk analysis on personal data has been conducted on the prestudy scope
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** Analyse the risks of a new processing. The risks concern the impacts on the data subjects (Persons) if the personal data were destroyed, modified (loss of integrity) or involuntary disclosed.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Analyse the risks of a new processing. The risks concern the impacts on the data subjects (Persons) if the personal data were destroyed, modified (loss of integrity) or involuntary disclosed. 

This requirement is to ensure that a first general analysis is done, in order to estimate the level.
