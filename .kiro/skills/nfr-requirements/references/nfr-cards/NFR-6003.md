# NFR-6003 — Treatment of security vulnerabilities

## 1. NFR Metadata

- **ID:** NFR-6003
- **Title:** Treatment of security vulnerabilities
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** This provision aims to fix vulnerabilities published systems or software and also the vulnerabilities found in applications. Monitoring of security flaws related to the operating systems and software is organized with the help of publishers and a specialist service provider.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Cloud context: patching and product upgrades are always done first through pre-production to ensure that the application remains operational due to increased product release
- On AWS: Use preferably automatical updates if you can, and depending the D (from DICT) of your application.

## 5. Governance & Management Data

### Variant (NFR-6003a)

**Description:** Must be done before the end of the BUILD phase, or must be planed to be done after, if any non-critical security vulnerability is detected during BUILD.

**Cases of dispensation:** No dispense possible

**Impacted deliverables:** Testing dossier - Security qualification
