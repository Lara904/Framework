# NFR-6403 — Accesses of third party applications must be traced

## 1. NFR Metadata

- **ID:** NFR-6403
- **Title:** Accesses of third party applications must be traced
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** The purpose of this provision is to have information on the activity of client applications on the concerned application. In the data to back up any information for characterizing the safest way possible, the calling application is desired.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Cloud context: have a file or connection traces when connects
On AWS: Enable logging on S3 accesses.
