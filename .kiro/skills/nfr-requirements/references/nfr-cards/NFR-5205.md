# NFR-5205 — Time ranges for user's activities, for batch processing and for technical maintenance are validated with the users

## 1. NFR Metadata

- **ID:** NFR-5205
- **Title:** Time ranges for user's activities, for batch processing and for technical maintenance are validated with the users
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** Details: For maintenance of components (operating and system) and server hosting the application, it is mandatory to define availability ranges for users, for batch processing and for technical maintenance. These ranges must be validated with users and must be written in REFLEX.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- For cloud applications (IAAS, PAAS, CAAS, and SAAS): you find all this information of opening, closing and maintenance under Reflex for each application

Example:
- For PEPSI application, availability ranges are:
- For users’ activities: Monday to Friday, from 8:00am to 5:00pm
- For batch processing: all days, from 8:00pm to 8:00am
- For technical maintenance:
- All days from 5:00pm to 8:00pm
- Saturday and Sunday from 8:00am to 8:00pm
