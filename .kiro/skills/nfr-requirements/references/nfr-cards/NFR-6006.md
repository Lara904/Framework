# NFR-6006 — The system must provide tools for application "reporting" (dashboards, etc.)

## 1. NFR Metadata

- **ID:** NFR-6006
- **Title:** The system must provide tools for application "reporting" (dashboards, etc.)
- **Primary Category:** Security

---

## 2. Executive Summary

- **The "Goal":** This provision aims to organise the reporting of information required by the MOA to respond to the legal requirements or if desired to react rapidly to certain predetermined events. Its implementation means the use of a "traceability" application module in the application to establish and present the data monitored according to the requirements expressed by the MOA (occasional reporting upon defined event such as occurrence of access, of a threshold being passed, etc…).
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Security standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).
