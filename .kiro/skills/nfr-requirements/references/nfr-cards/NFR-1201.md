# NFR-1201 — For processes, which uses a functional date, the programs must use a functional date independent from the machine's date

## 1. NFR Metadata

- **ID:** NFR-1201
- **Title:** For processes, which uses a functional date, the programs must use a functional date independent from the machine's date
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** The functional date is user data which will be logged in an application file used for processing. It ensures functional independence of processing compared to execution date and time.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- The functional date is user data which will be logged in an application file used for processing. It ensures functional independence of processing compared to execution date and time.

Realization:
- Use application calendars only for processing management; do not rely on machine date (if a day processing « D » is executed after midnight, for reasons of load or other, it will be dated at « D » and not « D+1 »).
