# NFR-5101 — The system must be designed and realized to be operated by the Operations with their usual tools

## 1. NFR Metadata

- **ID:** NFR-5101
- **Title:** The system must be designed and realized to be operated by the Operations with their usual tools
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** (See document for details.)
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- Criteria not applicable for z/OS except USS

Detail:
- The objective is to be able to monitor the application remotely.

IT-PM must include the « deport console » [console offset] hardware in the project cost, for the monitoring site and the site is implanted in the servers.
- On Cloud platforms (AWS, AZURE, GCP …)
- Operations can be able to perform actions on resources, stop/restart and checks resources and applications as well as other operating tasks. 

Realization:
- The system integrator requests the operations to conduct a connection test in the production machine, by using the appropriate environment implemented during its installation.
- On Cloud platforms (AWS, AZURE, GCP …)
- Procedures must be provided by the project team (applicative and infrastructure tasks)
- Connection is made through provider Console using this guide: AWS AZURE - Handling Guide
