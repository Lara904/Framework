# NFR-1203 — The time's reference must be guaranteed and its good usage must be checked periodically

## 1. NFR Metadata

- **ID:** NFR-1203
- **Title:** The time's reference must be guaranteed and its good usage must be checked periodically
- **Primary Category:** Functional Suitability

---

## 2. Executive Summary

- **The "Goal":** Ensure that the time reference is guaranteed (ICC more and Vision INFRA) This is to ensure that all information used to mark time is derived directly or indirectly from a reference clock, usually the NTP server STELLANTIS. Monitor the proper consideration of the time reference (more INDUS Vision)
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Functional Suitability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- On Cloud platforms (AWS, AZURE, GCP …):
- Time reference guaranteed by the configuration you have implemented.
