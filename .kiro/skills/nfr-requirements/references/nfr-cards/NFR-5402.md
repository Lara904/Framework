# NFR-5402 — The system has tested shut-down and restart plans for hardware, OS, products and system itself

## 1. NFR Metadata

- **ID:** NFR-5402
- **Title:** The system has tested shut-down and restart plans for hardware, OS, products and system itself
- **Primary Category:** Reliability

---

## 2. Executive Summary

- **The "Goal":** This is to test OS instance reboot (stop-start of the system, and products) and reboot on alternate system disks (when this architecture is implemented). NB: in the documents meant for operations, the equipment’s related to automate must be designated by their network name.
- **Why it matters:** Failure to implement this NFR may result in non-compliance with Reliability standards, increased operational risk, and potential rejection during technical control gates (TCC/CTC).

---

## 3. Technical Requirements

### Key Constraints

- The system integrator must develop not interactive scripts who will execute stop and start of the application (1 script for stop and 1 script for start). These scripts will be used and called by the monitoring menu. 
In case of presence of an alternate disk, the operator will execute a first reboot on alternated disk from the monitoring menu, and then he will execute an additional reboot to return to the primary disk.
In each reboot, the system integrator will validate the correct restart of the application and associated products.
The robustness tests of hypervisor who hosts the OS instances (alternated, mirror, multipathing) are not validated in this phase, but executed upstream by the system experts in the delivery of the server.
The operating range describing these actions should be stored in REDEX
The system integrator must perform the stop-restart test of the application, and then perform it in the operations by system control, in preproduction context. This test is to be re-performed on production machine to validate the correct application installation.
- Cloud context: OPS will perform its various tasks during the pre-production phase before going into production to verify that everything is in nominal operating condition.
