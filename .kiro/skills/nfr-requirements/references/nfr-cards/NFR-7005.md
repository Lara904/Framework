# NFR-7005 — The FINOPS principles must be implemented

## 1. NFR Metadata

- **ID:** NFR-7005
- **Title:** The FINOPS principles must be implemented
- **Primary Category:** Maintainability

---

## 2. Executive Summary

- **The "Goal":** FINOPS is a continuous, iterative journey that projects must embark for all deployments on the cloud. The goal of FINOPS activity is to balance cost, speed and quality in order gain cloud efficiencies.
- **Why it matters:** If not implemented, all applications/projects to be deployed in a public cloud.. Failure to comply may lead to non-conformance with group standards and audit failures.

---

## 3. Technical Requirements

### Key Constraints

- The implementation of FINOPS takes place across three phases, with each phase guided by the six core principles. Those phases are: Inform (visibility & allocation), Optimize (utilization, rates), Operate (Continuous improvement & operations).
- The detail of resource consumption by project is available via the cloud provider’s tools (consoles)
- These should be monitored regularly (at least monthly) and shared with the entire team.
- On any unjustified cost drift and / or deviation from consumption forecasts, carry out an analysis to detect the reasons and implement the appropriate optimizations (project environments that are no longer used, development servers not stopped during the WE, database of cut data ...)
- Follow project forecasts and adapt them if necessary (functional scope extension)
- FINOPS is a combination of people, process, and tools.
- People:  IT-PM should define clearly the different roles for each contributor (executives, FinOps practitioners, Engineering/OPS/Infrastructure and Finance & Procurement) by collaboration with infrastructure team (Move to cloud team, Gouvernance team, partner’s team)
- Process: IT-PM should control that the cost management and the FinOps activity are integrated in the complete lifecycle of each application deployed in the cloud. This applies to design, build, run and continuous optimization.
- Tools: IT-PM ensure that the various contributors to the project use the Stellantis recommended tools for FinOps activity. The actual recommendation is to use the cloud providers tools dedicated to cost management.
